## A-1. 피영향국 미기재 건의 자기표시 버그 — 완료 (로컬), 배포 대기

**증상**: 피영향국=China, 시행국=China로 필터하면 "China ← China" 자기타깃처럼 표시됨.

**원인**: GTA 데이터 오류가 아니다. `China: Temporary suspension of additional export controls...`(같은 state act)가 GTA에 intervention 3건으로 쪼개져 있다.

| intervention_id | affected_jurisdictions |
|---|---|
| 150488 | 약 150개국 나열 |
| 150492 | 약 59개국 나열 |
| **150493** | **비어 있음(None)** |

"피영향국 미기재 건은 어느 나라를 골라도 항상 포함"이라는 기존 화면 규칙이 시행국=피영향국 필터가 같은 나라로 겹치는 경우와 만나면서 150493이 자기타깃처럼 노출됐다.

**조치**: `countryRows()`에 예외 추가 — 두 필터가 같은 나라일 때만 미기재 건을 제외.

```js
const selfTarget = state.affected && state.implementing && state.affected === state.implementing;
function countryRows(){return D.measures.filter(m=>
  (!state.year||(m.date&&m.date<=state.year+'-12-31'))
  &&(!state.affected||(m.affected_missing&&!selfTarget)||m.affected.includes(state.affected))
  &&(!state.implementing||m.implementing.includes(state.implementing)))}
```

**검증**: `python -c` 로 `site/semi.json` 실측 — `affected=China, implementing=China` 필터 결과 0건(150493 제외 확인), 다른 조합에서는 그대로 포함됨.

**미완료**: Cloudflare 배포는 승인 후 진행.

## A-2. 색칠 로직 — "최근 조치 1건" → "다수결" — 완료 (로컬), 배포 대기

**배경**: 기존 방식(국가쌍별 가장 최근 조치 1건이 색을 결정)은 설계문서(`설계_반도체공급망화면.md` 3-D)가 이미 실측 후 폐기 결정했다(UAE 우대 조치 1건이 미국 칩 코드 5개를 통째로 뒤집는 등). 그런데 배포된 코드에는 그 폐기 결정이 반영되지 않고 있었다.

**2026-08-14 결정(사용자 직접 지시)**: 설계문서의 "Red-only + 비중 농도" 안 대신, **다수결 방식**을 채택한다.

- 국가(또는 HS 코드)별로 **지금까지 쌓인 조치 중 레드+앰버 건수 vs 그린 건수**를 세어 많은 쪽으로 색을 정한다
- **앰버는 별도 색을 쓰지 않고 레드로 합친다** — Red/Green 두 색만 존재
- **동률이면 가장 최근 조치의 색**을 따른다
- 만료·철회 여부는 다수결 집계에서 제외하지 않는다 — "지금까지의 track record"를 보는 것이므로 끝난 조치도 그대로 센다. 만료 사실은 색이 아니라 타임라인에 개별 표기(`expired()`)

**주의 — 이건 설계문서 3-D의 최종 결론과 다른 방식이다.** 3-D는 Red만 쓰고 비중으로 농도를 매기자고 했으나, 실제 채택된 것은 Red+Amber vs Green 건수 다수결이다. 설계문서를 이 결정으로 갱신하지는 않았다 — 필요하면 별도로 정리할 것.

**구현**:

```js
function bucket(ev){return ev==='Green'?'green':'red'}
function tally(rows){let red=0,green=0;for(const m of rows){if(bucket(m.evaluation)==='green')green++;else red++}return{red,green}}

// 나라별(세계지도) — EU 공동조치 규칙(자국 우선)은 유지
function perCountry(rows){let out={};for(const m of rows){for(const c of m.implementing)(out[c]??=[]).push(m)}
 return Object.fromEntries(Object.entries(out).map(([c,x])=>{const own=x.filter(m=>!m.implementing_groups.length);
  const pool=own.length?own:x,{red,green}=tally(pool),rec=latest(pool);
  const colour=red===green?bucket(rec.evaluation):(red>green?'red':'green');
  return[c,{...rec,colour,red_count:red,green_count:green,has_joint:x.some(m=>m.implementing_groups.length),from_joint:!own.length}]}))}

// HS 타일 — 여러 나라가 걸리므로 국가별로 나누지 않고 rows 전체를 그대로 다수결
function status(rows){if(!rows.length)return'';const{red,green}=tally(rows);if(red===green)return bucket(latest(rows).evaluation);return red>green?'red':'green'}
```

**검증**: `site/semi.json` 실측 — 피영향국=Korea, 시행국=China 필터에서 레드(+앰버) 15건, 그린 13건 → 레드 다수결로 색 결정. `.hs.mixed`/`.hs.amber`/`.hs.history`, `.country.amber`/`.country.expired` CSS 클래스는 더 이상 생성되지 않는다(CSS 자체는 남아 있으나 미사용).

**타임라인 카드**: 국가별 "가장 최근 조치" 카드에는 그 카드 자신의 evaluation으로 색 있는 제목을 준다 — 다수결로 정해진 지도 색과 다를 수 있으며, 그게 정상이다("최근에 뭔 일이 있었는지"를 알려주는 것이지 지도 색의 근거가 아니다).

## B-1. 세계지도 연도별 선택 — 완료 (로컬), 배포 대기

**지시**: 세계지도에서 연도별로 볼 수 있게 한다. 기준은 **해당 연도 12/31**. A-2의 다수결 규칙과 함께 적용된다 — 특정 연도를 고르면 그 해 12/31까지 발표된 조치만으로 다수결을 다시 계산한다.

**구현**:

```js
function countryRows(){const selfTarget=...;
 return D.measures.filter(m=>
   (!state.year||(m.date&&m.date<=state.year+'-12-31'))
   &&...)}

function fillYears(){const years=[...new Set(D.measures.map(m=>(m.date||'').slice(0,4)).filter(Boolean))].sort();
 $('#year').innerHTML='<option value="">전체</option>'+years.map(y=>`<option value="${y}">${y}-12-31 기준</option>`).join('');
 $('#year').value=state.year;$('#year').onchange=()=>{state.year=$('#year').value;render()}}
```

필터 패널에 "기준연도" 드롭다운을 추가했다. 기본값 "전체"(연도 제한 없음). 특정 연도 선택 시 지도 헤더와 요약 배지에 `YYYY-12-31 기준` 표기가 붙는다.

**검증**: `site/semi.json` 실측 — 피영향국=Korea, 시행국=China 기준 연도별 누적 조치 수(2018: 8건 → 2020: 9건 → 2022: 10건 → 2024: 13건 → 2026: 28건, 단조 증가 확인).

**미구현(다음 단계로 남김)**: "그림이 안 바뀌는 해는 생략하고 바뀌는 시점만 표시"는 아직 안 만들었다 — 지금은 모든 연도를 수동으로 하나씩 선택해야 한다. 자동 변화점 탐지는 별도 작업.
