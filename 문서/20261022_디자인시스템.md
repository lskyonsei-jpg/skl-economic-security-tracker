# 디자인 시스템

## 핵심 판단

- 참조 사이트의 요체는 색이 아니라 절제다. 연회색 바탕, 단색 민트 띠 하나, 대문자+자간 라벨, 모서리 없는 얇은 외곽선, 넓은 여백.
- 서체는 Gudea(라틴·숫자) + Noto Sans KR(한글). 제목도 굵기 400. 굵기 대신 크기와 자간으로 위계를 만든다.
- 토큰은 `assets/site.css` 하나에 둔다. 화면별 CSS 는 토큰만 참조하고 색 리터럴을 쓰지 않는다.

## 참조 사이트에서 실측한 값

| 항목 | 값 |
|---|---|
| 바탕 | `#f8f8f8`, 글자 `#2f2f2f`, 보조 `#4f4f4f`·`#888888` |
| 띠(히어로) | `#7ec8c5` 민트 단색 |
| 보조 강조 | `#4dd2a7` 녹색, `#ff8770` 코랄, `#6dd0f8` 하늘, `#111827` 남색 |

| 버튼 | 0.8px 실선 외곽, 모서리 0, 13px 35px 패딩, 14px 대문자 자간 2px, 바탕 투명 |
| 본문 | 16px / 24px |
| 최대폭 | 1200px |

## 의미색

- 순차 척도(리스크·노출): `--seq-0` 회색 → `--seq-5` 짙은 청록. 많을수록 짙게.
- 블록 3분류: 자국 블록 청록(`--bloc-self`), 비동맹 회색(`--bloc-neutral`), 상대 블록 코랄(`--bloc-other`).
- GTA 평가: Red/Amber(해로움)는 코랄 계열, Green(자유화)은 녹색. 환경 분류가 아니라는 문구는 유지.
- 범주형 선(국가 추이): `--cat-1`~`--cat-10`.

## 화면 구성

- 공통: 상단 내비(브랜드 + 패널 2개 + 데이터) → 민트 띠(제목·한 줄 설명·핵심 수치 3~4개) → 본문 패널들 → 방법론 접힘 → 남색 푸터(자료 기준일·빌드 시각·커밋).
- 패널 1 Distortive Industrial Policy Tracker: 기존 상호작용(지도·순위·추이·산점도·구성)은 그대로, 외관만 토큰으로 교체. "최근 변경" 섹션을 상단에 추가(변경 리포트 흡수).
- 패널 2 한미 AI 협력 트래커: 타임라인(형태별 마커, 행정부 경계선), 분야×형태 매트릭스(count·share·분모), 주체 연결(미국 주체 ↔ 한국 주체), 확정계약 누적 금액(선언 포함치는 점선), 원문 표.

## 하지 않는 것

- 그라데이션, 그림자, 둥근 모서리, 굵은 제목, 색 3개 이상의 장식.
- 모델 예측(BERT 후보군)을 확정 라벨처럼 보이게 하는 색·문구.
